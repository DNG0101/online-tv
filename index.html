ABOUT STREAMDECK

Browser-first IPTV playback

Built for static hosting such as GitHub Pages. It parses M3U playlists in your browser and uses native HTML5 video or hls.js where available.

VLC can open protocols and codecs that browsers cannot. A failed browser playback attempt is usually a provider, CORS, protocol, or codec limitation—not a playlist parsing failure.
